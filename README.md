## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For a local development server, open the folder in VS Code and use Live Server.

## Publish online
You can deploy the folder with GitHub Pages, Netlify, or another static website host. Upload all three website files while preserving their filenames and folder structure.
